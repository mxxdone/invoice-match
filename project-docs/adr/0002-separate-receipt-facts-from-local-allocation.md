# 외부 검수 사실과 로컬 검수 배분의 정본을 분리한다

발주·검수 사실과 external version은 외부 구매시스템을 정본으로 유지하고, 이 시스템에서 어떤 청구가 검수수량을 소비했는지는 `ReceiptAllocation`을 정본으로 관리한다. 승인 전에 외부 snapshot을 갱신하고 트랜잭션 안에서는 로컬 검수 행을 잠가 배분 합계가 검수확정수량을 넘지 않게 한다. 외부 시스템까지 잠그거나 분산 트랜잭션으로 묶었다고 주장하지 않는다.

## Consequences

- 승인 중 외부 API 호출로 DB 잠금을 오래 유지하지 않는다.
- 외부 검수 version이 바뀌면 기존 검토 스냅샷은 다시 대사해야 한다.
